CIS–HR Study Companion — iPhone offline edition

Upload ALL these files to the root of a GitHub repository (or a folder published by GitHub Pages). Enable GitHub Pages for the published branch and open its HTTPS link in Safari. While ONLINE, open once and let the site load; then use Safari Share > Add to Home Screen. Open the installed app once online before relying on offline mode. Test airplane mode.

The service worker caches the HTML and app icons; all 200 questions are embedded in index.html. External documentation references do require Internet. Progress is stored on each browser/device; use Export/Import to migrate or back up progress. A local file opened via Files will not register a service worker.

Note: This remains a preliminary independently authored question bank, not an officially validated set.
